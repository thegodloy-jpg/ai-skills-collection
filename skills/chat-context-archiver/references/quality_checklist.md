# Quality Checklist

Run this checklist before final output.

## Content quality

- [ ] Goal is explicit and matches user intent.
- [ ] Constraints and non-goals are separated clearly.
- [ ] Decisions include rationale and status.
- [ ] Progress reflects completed vs pending work accurately.
- [ ] Risks are concrete, not generic.

## Path quality

- [ ] Includes actionable file/folder paths from the conversation.
- [ ] Paths are not fabricated.
- [ ] Paths are consistent with platform style.

## Language quality

- [ ] Main content is in English.
- [ ] Key headers or notes include concise Chinese annotation.

## Output contract

- [ ] If target file exists, timestamp suffix is applied automatically.
- [ ] Final response is exactly one line:
  - `Context saved: <absolute_path>`
